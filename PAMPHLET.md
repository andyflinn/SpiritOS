# SpiritOS — start here

A personal node on **your** machine. One public relay: [spirit.andyflinn.com](https://spirit.andyflinn.com).

Your browser talks only to you, plain HTTP on `http://localhost:65432`. The personal node talks to the relay over **HTTPS**. You do not browse the VPS as a website.

## Run

```
git clone https://github.com/andyflinn/SpiritOS.git
cd SpiritOS
npm start
```

Open `http://localhost:65432`. No `npm install` for the server.

First paint is **only Relay Chat**. That is deliberate.

## Get on the relay

You need a name and, unless you own the box, a spoken word from Andy.

- Invited: type that name and the word, then **Claim**.
- No invite yet: write **countinn@gmail.com** — you get a word within 24 hours.
- You own this relay: claim it with the owner invite `node install.js` mints over SSH.

After Claim the rest of the shell appears.

## What this is not

Not a cloud account. Not a public directory of strangers. Contacts live on your disk. The relay does not block people for you.
