# spirit/type/string/IDNew/script.js

The type spirit.type.string.IDNew: the key type for adding a contact (goal/G48.4, Q12, Andy: *"similar to <type>Select.js
<type>New.js expands to allowable values."*): every key `spirit.type.string.ID` takes, and a well-formed key nobody here has
seen yet. Its test: `./script.js`. What every type file and every `<type>New.js` keeps is judged by
`spirit/test/script-sibling-general.js` (its type rules).

## What its test judges

It exists and loads; isValid answers true for a well-formed key made just now, which no node has seen; it throws for an item
name, an empty string, a key cut short and a key with a space.
